
# C-Analysis: SDM Tutorial *(R Project)*

Project: Is Nordic cloudberry moving with climate change? A transmedia guide to species distribution modelling with MaxEnt

Author: Nicole K. J. Drewitz Project Affiliation: University Centre of the Westfjords, Master of Coastal and Marine Management

**The scripts in this project help** sample values from the final MaxEnt model to produce figures and tables for analysis to **answer the thesis research questions**. Also visualizes changes in environmental variables at presence locations across climate scenarios, and the correlation between environmental variables. Can be used to analyze species distribution models (as raster files) created with other biostatistical methods. As MaxEnt uses penalized logistic regression for modelling, these analyses focus on observing differences in effect sizes rather than additional statistical analysis.

AI Use: Scripts were drafted with Claude, and sometimes debugged with Claude or Perplexity

SDM Guide: https://arcg.is/aP8eq0

Thesis: Skemman.is

## Usage

1.  (Re)place any source files in the `/Input_files` folder, or set new file paths. **Required:** A habitat suitability raster ready for analysis (e.g. ASC), presence/absence locations reserved for model analysis (CSVs), final environmental variable rasters, and a vector file with polygons for regional analysis _(optional)_.

2.  Run scripts matching your research questions from the scripts folder:

    ``` r
    R/
    ```
## Research Questions and Aims
>***Questions:***
>
>1. What environmental variables best explain current cloudberry habitat suitability? 
>2. How well does this model perform? 
>3. Where are highly suitable cloudberry habitats, and how is their spatial distribution predicted to shift under different climate change scenarios? 
>4. Will coastal or inland regions see greater shifts in habitat suitability and habitat area? 

>***Aims:***
>
>a. Identify ecoregions with the greatest mean change in habitat suitability. 
>
>b. Summarize changes in environmental variables across key ecoregions. 

## Folders and R Scripts Summary

-   `R` folder _(some have options to uncomment different figure formats)_:
    -   `Q1-Important_environmental_variables` subfolder
    -   `Q2-Model_performance` subfolder
    -   `Q3-Moving_suitability` subfolder
    -   `Q4-Regional_comparisons` subfolder

    -   Scripts named according to the research question and a letter for the order of scripts (e.g. `Q#-a`).
    - Those named with "0" instead of a letter are used to extract values, creating the CSVs used in analysis and figure creation (e.g. `0-`, `Q#-0a` and `Q#-0b`). These scripts require links to larger raster files.

-   `Input_files` folder:
    -   `Environmental_variables` subfolder
    -   `MaxEnt_files` subfolder 
    -   `Modelling_area-regional_divisions.gpkg` (regional polygons vector)
    -   `Random_sampling_locations` subfolder: create with `Q#-0a` scripts or design your own points.

-   `Data` folder
    -   Used to hold location CSV files with sampled values.

-  `analysis_output_data` folder
   -   Used to hold CSVs with analysis summary data.

- `figures` folder


## C. Analysis

*See thesis for more details: <skemman.is>. Question numbers align with thesis subsection numbers.

>### 1. Important environmental variables 
>
> **Required:** a. Environmental variable rasters
>
> a. Correlation matrix
>
> b. Response curves matrix

>### 2. Model performance
>
> **Required:** Presence/absence locations reserved for model analysis CSVs, CSV from fine-tuning settings model iterations ("model_predictions_comprehensive.csv"), and stepwise comparisons ("habitat_suitability_all_stepwise_runs.csv")
>
> a. Recreate plots for selection of best settings by AICC comparison.
>
> b. Model performance plots
>
> c. Spatial autocorrelation plots

>### 3. Moving habitat suitability
>
> **Required:** Environmental variables rasters
>
> a. Difference in suitability between scenarios mapped
>
> b. Change in the area of suitable habitat
>
> c. Change in environmental variables

>### 4. (Eco)regional comparisons
>
> **Required:** Vector of regions to compare, first use `Q4_0` scripts to generate sampling points (a), and sample values from rasters (b). `Q4_0` scripts are also used to find the area above suitability thresholds (c).
>
> a. Use `Q4-0` scripts to generate CSVs for highly suitable habitat area data.
>
> b. From CSVs generated by `Q4-0` scripts, create figures showing changes in mean habitat suitability by ecoregion.
>
> c. Create 100% stacked area bar charts of each ecoregion and climate scenario.
>
> d. Create tables of change of environmental variables within each ecoregion. Created from data extracted into CSVs with `Q4-0d` script. Tables can be colour-coded with conditional formatting in Excel.
